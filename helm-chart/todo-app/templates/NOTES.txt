  🌐 ACCESSING THE APPLICATION
========================================================================================

{{- if .Values.frontend.enabled }}
{{- if eq .Values.frontend.service.type "NodePort" }}

1. Get the Minikube IP:
   $ minikube ip

2. Access the frontend application:
   $ open http://$(minikube ip):{{ .Values.frontend.service.nodePort }}

   Or use: http://localhost:{{ .Values.frontend.service.nodePort }}
   (if you have port-forwarding configured)

{{- else }}

1. Forward the frontend port:
   $ kubectl port-forward service/{{ include "todo-app.fullname" . }}-frontend {{ .Values.frontend.service.port }}:{{ .Values.frontend.service.port }}

2. Access the application:
   $ open http://localhost:{{ .Values.frontend.service.port }}

========================================================================================
  🔍 MONITORING & DEBUGGING
========================================================================================

Check pod status:
  $ kubectl get pods -l app.kubernetes.io/name={{ include "todo-app.name" . }}

View frontend logs:
  $ kubectl logs -l app.kubernetes.io/component=frontend --tail=50 -f

View backend logs:
  $ kubectl logs -l app.kubernetes.io/component=backend --tail=50 -f

Describe a specific pod:
  $ kubectl describe pod <pod-name>

Execute commands in a pod:
  $ kubectl exec -it <pod-name> -- sh

========================================================================================
  🔧 TROUBLESHOOTING
========================================================================================

If pods are not starting:
  1. Check pod events: kubectl describe pod <pod-name>
  2. Verify secrets exist: kubectl get secret {{ .Values.secrets.name }}
  3. Check logs: kubectl logs <pod-name>

If you see ImagePullBackOff:
  - Ensure images are loaded: minikube image ls
  - Verify pullPolicy: {{ .Values.frontend.image.pullPolicy }}

If services are unreachable:
  - Check service: kubectl get svc
  - Verify endpoints: kubectl get endpoints
